# AML Laundering-Network Detection & Triage

> **Status: in development.** Built to the plan in `PROJECTSep_v3.md`.
> This README is a skeleton — every number in it will be generated from
> `results/*.json` on Day 10, not typed by hand.

Detects money-laundering networks in transaction data using graph-derived features on
a gradient-boosted model, then uses an LLM agent to triage flagged alerts and draft
investigator-ready case narratives. Evaluated with controls on both halves.

Where this sits in the real compliance workflow:

```
transaction monitoring  ->  alert  ->  L1 triage  ->  L2 investigation  ->  SAR decision
    [ this project: engine ]      [ this project: agent ]
```

## Quickstart

```bash
# Python 3.13 is required — see docs/NOTES.md for why 3.14 does not work
/Library/Frameworks/Python.framework/Versions/3.13/bin/python3.13 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt

# macOS without Homebrew: repair LightGBM's OpenMP link
make fix-libomp

make check      # verify the environment
make all        # full pipeline: raw data -> every reported number
```

Credentials go in `.env` (copy from `.env.example`). Nothing is committed.

## Dataset

IBM *Transactions for Anti-Money Laundering* (Altman et al., NeurIPS 2023 Datasets &
Benchmarks), HI-Small variant. Synthetic, per-transaction `Is Laundering` labels, and
a companion `Patterns.txt` giving ground-truth typology labels for eight injected
laundering patterns.
